# Apple data framework references

- Core Data: https://developer.apple.com/documentation/coredata
- SwiftData: https://developer.apple.com/documentation/swiftdata
- CloudKit: https://developer.apple.com/documentation/cloudkit
- CloudKit Web Services reference (Apple Documentation Archive): https://developer.apple.com/library/archive/documentation/DataManagement/Conceptual/CloudKitWebServicesReference/

Apple currently exposes the Web Services reference through its documentation
archive. Treat it as the official protocol starting point, not proof that every
Dashboard, authentication, quota, or endpoint behavior is unchanged. Verify the
current CloudKit Console/container configuration and live Apple documentation
for the selected environment before implementation.
